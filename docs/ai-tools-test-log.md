# AI tools test log: FDD 3084 Fixed Asset Removal (model testcust)

Scenario: implement `FDD_Fixed_Asset_Removal_FO_V3.0.docx` end to end using only the agent (MCP) tools of this
extension, starting from an empty `testcust` model. Every tool problem found is logged here with its fix.

Status legend: **Fixed** (fixed in this branch and re-tested), **Open**, **By design**.

Re-test: `node scripts/tool-regression.js --project <TestProj.rnrproj>` runs one check per tool issue (cases in `scripts/tool-regression.json`, tagged with the issue number).
